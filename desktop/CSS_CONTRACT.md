# Theme, cascade and responsive contract

Verified 2026-10-11. The shell's `--theme-*` tokens in `src/app.css` are canonical. The original root `--ink`, `--panel`, `--green` and related names retain fallback values for standalone markup; inside `.app-shell` they are compatibility aliases to the canonical tokens. Do not introduce another independently maintained palette. The earlier `[data-theme="dark"]` rules provide compatibility selector overrides; the later `.app-shell[data-theme="dark"]` token block controls the full shell palette. Instrument overrides remain in `src/instrument.css`, keyed by `html[data-instrument]` and loaded after `app.css`. Phosphor, Ion and Breach retain their signal/workflow-art tokens. `styles/type-scale.css` follows both and controls the common reading scale.

`+layout.svelte` loads base, instrument and type-scale sheets. Feature components import Home, Library grid and metadata-review sheets or own Svelte styles. Shared run, upload, settings/provider/cache/filter, reports/diagnostics, repair/log and recovery selector families remain explicitly scoped in `app.css`; `UI_OWNERSHIP.md` records their consumers. Shared form/button tokens remain shared because several workflows use them. Their cascade has not been flattened or replaced during extraction.

The global viewport floor is 360px at every width. The former 1000px base floor was superseded by a later 360px rule; those contradictory declarations are now one rule. Main/grid children retain `min-width: 0`; large media tables scroll locally. Existing compact shell breakpoints, feature wrapping, dialog viewport bounds and focus styles remain. Acceptance widths are 360, 390, 620, 800, 1024 and 1440. Browser fixtures use the same three global sheets and set the same HTML theme/instrument attributes as the real shell. Browser screenshots prove those fixtures only; native responsive acceptance is recorded separately.
