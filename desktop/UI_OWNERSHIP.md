# UI ownership and extraction contract

Verified against `src/routes/+page.svelte` on 2026-10-11. The route coordinates native IPC, persisted preferences/queue, safety confirmations and run events. Components receive typed data and callbacks; they never create another competing queue or launch a job independently.

| Slice / owner | Inputs / state class | Outputs and side effects | CSS owner / scope | Regression and rollback boundary |
|---|---|---|---|---|
| Shell / route | Navigation, theme, desktop availability: shared app state | `openPage`, persistence, native listeners and cleanup | `app.css` shell, tokens and responsive aliases | Navigation/active-job restrictions; restore shell bindings only |
| Home / HomeDashboard | Environment, counts, active folder, activity, reports/setup logs: read-only shared projections | Open page/report, add folder/files, refresh diagnostics callbacks | HomeDashboard local styles; shared shell tokens; WorkflowIllustration instrument CSS | Missing/ready tools, recent runs, setup logs, actions, all skins |
| Help / HelpCenter | Static command/help content: feature local | Existing links/examples only | HelpCenter local styles + shared typography | All commands/modes reachable; no IPC moved |
| Library / LibraryQueueStatus + LibraryPosterGrid + library-browse | Scan result/progress, queue sources/selections/run states/reviews: shared app state; breadcrumb/search/page: feature local | Select/mark animation, open review/location, remove/refresh via route callbacks | Grid/TV review local styles; library chrome explicitly scoped in shared library CSS | Empty/populated, scan, selection persistence, series/season/episode hierarchy |
| TV review / LibraryTvReview | Explicit series/season/episode field values: route persisted review data; presentation local | Typed field/poster/animation callbacks | LibraryTvReview local styles | Shared-field inheritance, episode overrides, alternate artwork |
| Metadata / MetadataWorkbench | Scan/focused path, reviewed assignments/templates/provider status: shared state; lookup/search/form drafts local | Lookup status/suggestions, renames, settings, metadata-only start, assignments via existing bindings | MetadataWorkbench local styles; shared modal shell | Validation, local NFO, provider safety, output boundaries, close/reopen |
| Rename / LibraryRenameDialog + rename-template + route coordinator | Draft templates/preview/errors/busy: feature local; selection and persisted templates: shared | Preview/apply through native commands with exact preview ID + confirmation; route updates queue paths | Rename/modal styles scoped to rename class | Tokens, collision preview, selected/all files, folders/sidecars, cancel/error |
| Queue/run / typed lifecycle controller | Queue sources, selections, run states/report references: shared; pending batches/active index/stop state: orchestration | Route owns IPC and persistence; typed transitions expose queued/active/stopped/failed/recovered/stale | No CSS; consumers own rendering | Empty/populated, stale events, active-job restrictions, recovery on reopen |
| Run / RunProgress + RunConsole + ResourceTelemetry | Run lines/progress/resource snapshots and report association: read-only run state | Stop/cancel/open details/report callbacks; never forecasts unknown values as zero | Telemetry local styles; console/progress styles scoped to view | Progress, ETA, CPU/RAM/disk/calibration, unknown values, all terminal states |
| YouTube / YouTubePreparation | Selected entries, resolution/quality/multiplier/output, HDR policy: shared preferences + feature drafts | Explicit preparation confirmation/stop via route; no upload/authentication added | YouTube styles scoped to preparation view | Upload versus Live guidance, HDR10+ opt-in/skip, unsupported HDR/DV, output/no-overwrite |
| Settings / SettingsPreferences | Shared preferences/effective settings; credential drafts/cache state feature local | Explicit save/provider/cache callbacks; route owns secrets/native IPC | Settings CSS scoped to settings feature; shared form tokens | Read-only diagnostics, override readiness, validation, save/error |
| Tool repair / ToolRepairActivity + ToolRepairConfirmation | Environment/APT exact plan/catalog/logs/busy/errors: shared diagnostics and feature execution state | Confirmed allowlisted repair/refresh; route retains administrator authentication and log export | Repair/log CSS scoped to view, shared modal shell | Stale catalog, exact plan, failure/cancel/log history; no actual APT mutation in tests |
| Reports / ReportBrowser + report-view | Reports/selection/rows/diagnostic excerpt: feature-local read-only state | Browse/open/export/retry callbacks; persisted queue updates remain route-owned | Reports CSS scoped to view | Exact report identity, missing/error/empty, bounded diagnostics |
| Recovery / RecoveryReview | Recorded queue outcome/report/probe, acknowledgment/index: orchestration plus feature review state | Explicit review/mark complete/retry; never automatic uncertain resume | Recovery CSS scoped to view, shared modal shell | Failed/stale/missing report/output; inspection does not substitute for validation |
| Modal / native dialog primitive | Controlled open state, label/description, busy/error content, backdrop policy | Escape/cancel/close callback; focus return to opener; background inert via `showModal` | Primitive owns backdrop/layout, caller class keeps feature style | Tab/Shift+Tab, Escape, background, focus return, validation/loading/cancel |

All public IPC/CLI/MCP payloads, native safety gates, media modes, source selection, provider policies and compatibility paths remain protected. Each vertical slice must move or explicitly scope its CSS in the same patch. Pure state tests precede slice movement; browser component checks precede native acceptance. Refactors must not relocate side effects merely to reduce route length.

Browser contracts: `pnpm test:home-help`, `test:library`, `test:rename`, `test:run`, `test:youtube`, and `test:support` exercise actual feature components against isolated synthetic props and callbacks. `ui-contracts.ts` owns shared preferences/credential status/recovery/log contracts; it contains no credentials. Shared `app.css` continues to own explicitly scoped run, upload, settings, reports, repair and recovery selector families. Fixture callback invocation is simulated IPC evidence, never account or native side-effect proof.

Cascade and viewport details: `CSS_CONTRACT.md`. `pnpm test:responsive` captures viewport snapshots at six widths across all five Home themes plus Library, Run, YouTube and report fixtures; it asserts document/main overflow and token presence. This does not replace native screen-size checks.
