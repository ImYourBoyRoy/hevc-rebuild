# UI ownership and extraction contract

Verified against `src/routes/+page.svelte` on 2026-10-11. The route coordinates native IPC, persisted preferences/queue, safety confirmations and run events. Components receive typed data and callbacks; they never create another competing queue or launch a job independently.

All public IPC/CLI/MCP payloads, native safety gates, media modes, source selection, provider policies and compatibility paths remain protected. Each vertical slice must move or explicitly scope its CSS in the same patch. Pure state tests precede slice movement (see `desktop/README.md` for the extracted-module tests and the route golden `pnpm test:route-golden`); browser component checks precede native acceptance. Refactors must not relocate side effects merely to reduce route length.

Browser contracts: `pnpm test:home-help`, `test:library`, `test:rename`, `test:run`, `test:youtube`, and `test:support` exercise actual feature components against isolated synthetic props and callbacks. `ui-contracts.ts` owns shared preferences/credential status/recovery/log contracts; it contains no credentials. Shared `src/styles/app/` continues to own explicitly scoped run, upload, settings, reports, repair and recovery selector families. Fixture callback invocation is simulated IPC evidence, never account or native side-effect proof.

Cascade and viewport details: `CSS_CONTRACT.md`. `pnpm test:responsive` captures viewport snapshots at six widths across all five Home themes plus Library, Run, YouTube and report fixtures; it asserts document/main overflow and token presence. This does not replace native screen-size checks.
