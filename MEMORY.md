## Architecture

- `desktop/src-tauri/src/settings.rs`: native GUI/JSON/MCP settings defaults, TOML/JSON overlay, validation, and precedence; `hevc_rebuild/config.py` remains the engine parser and parity reference (built-in, user TOML, saved profile, library `.hevc-rebuild.toml`).
- `desktop/src-tauri/src/resource_monitor.rs`: Linux-only read-only snapshots of CPU/load/PSI, effective host/cgroup RAM, swap occupancy/rates, engine/FFmpeg process RSS/VmSwap, temperature, and run-volume total/used/free storage. Tauri emits `run-resources`; MCP `get_job` returns `resource_snapshot`. It also exposes the shared stateful sampler used by the Rust-launched runtime guard.
- `desktop/src-tauri/src/runtime_guard.rs`: persistent Rust process that samples per-progress resources and owns memory-reserve, active swap-pressure, optional disk-reserve, and projected-output decisions during Rust-launched runs. Python maps returned snapshots to the established display/report types; `encode_supervisor.rs` owns FFmpeg child lifecycle for Rust-launched calls. Direct Python execution keeps the equivalent sampler, policy, and process runner.
- `desktop/src-tauri/src/resource_plan.rs`: shared run/scan profile-aware plan and quality-neutral retry calculations. Rust-launched runs sample affinity-aware CPU, effective RAM/cgroup allowance, swap, and memory PSI natively; the Python adapter applies returned worker/frame-thread counts to FFmpeg. Direct Python runs keep their planner/sampler fallbacks.
- `desktop/src-tauri/src/encode_plan.rs`: builds the full FFmpeg/x265 argument vector from the current selected stream set, per-video profiles, HDR/DV choices, deinterlace policy, and Rust resource plan. Rust-launched GUI/CLI/MCP runs call it through a bounded private helper; the Python reference remains for direct Python runs.
- `desktop/src-tauri/src/encode_supervisor.rs`: starts FFmpeg for Rust-launched encode calls, relays progress/diagnostics, returns exit/signal status, and stops the child on explicit cancellation or adapter-pipe closure. Python retains progress parsing, guard/retry orchestration, reports, and direct-Python fallback.
- `desktop/src-tauri/src/calibration.rs`: checks/writes the workload cache, computes machine/workload fingerprints, constructs bounded null-output calibration candidates, samples Linux RAM/swap/PSI, rejects unsafe runs, and selects a low-memory layout within the configured speed tolerance for Rust-launched jobs; Python supplies analyzed profile/options.
- `desktop/src-tauri/src/transactions.rs`: performs the final no-overwrite validated-output commit for Rust-launched runs, syncs the output, preserves the source under `old/`, installs the result, and attempts operation-time rollback on failure. Rust performs stream-level checks and Python performs remaining HDR/Matroska checks before this helper is called. Python still selects the backup filename; direct Python keeps the equivalent fallback. There is no crash-recovery journal.
- `desktop/src-tauri/src/packet_verify.rs` and `validation.rs`: Rust-launched GUI/CLI/MCP jobs compute fixed-memory FFmpeg framehash/SHA-256 fingerprints and compare selected stream order/count, codec parameters, payload hashes, timing, dispositions, chapters, and approved text edits. The Python adapter receives the bounded output probe for its remaining HDR-profile and expected Matroska tag/poster checks; direct Python retains its complete fallback.
- `desktop/src-tauri/src/hdr_metadata.rs`: Rust-launched HDR10+ FFmpeg/tool streaming verification and extraction plus Dolby Vision preservation/fallback eligibility reasons. The Python adapter retains direct-run functions and higher-level orchestration; Matroska metadata edits and the overall validation gate remain Python-owned.
- `desktop/src-tauri/src/metadata_text.rs`: bounded Rust substring-glob and conservative release-group-suffix cleanup for Rust-launched metadata text, including case-insensitive `Movie*Group` matching; Python keeps direct-run fallback, XML traversal, Matroska edits, and change reporting.
- `hevc_rebuild/metadata.py`: direct-engine reference/fallback for release-group suffix and validated custom blacklist cleanup, plus Python-owned readable Matroska/NFO extraction, XML mutation, poster attachment, validation, and change reporting; only matched text is removed, other technical values and stream payloads remain.
- `hevc_rebuild/encode.py`: Python compatibility adapter for Rust run plans/guards/FFmpeg arguments and the Rust supervisor; it still interprets progress, applies live guard outcomes/retries, and retains direct-Python process/planning/resource fallbacks.
- `hevc_rebuild/validate.py`: streamed packet fingerprints folded into fixed-size per-stream digests; do not restore whole-stdout capture or a packet-object list.
- `desktop/src-tauri/src/validation.rs`: owns selected-stream output verification for Rust-launched GUI/CLI/MCP rebuilds. It uses `packet_verify.rs` and bounded FFprobe output; Python retains the rest of the HDR/Matroska validation policy and final workflow decision.
- `hevc_rebuild/youtube.py`: separate source-aware SDR/HDR MP4 export workflow for one file or a folder; source files remain in place. GUI/CLI/MCP default to a 1440p target and balanced source-aware bitrate; higher sources are not downscaled. Scan results forecast output size and memory from chosen output dimensions. HDR uses HEVC Main 10 only with complete Rec. 2020/PQ/HLG tags and 10-bit x265 support; HDR10+ dynamic metadata is not retained, Dolby Vision is skipped, and source subtitles are omitted with per-file warnings.
- `hevc_rebuild/calibration.py`: bounded null-output x265 thread-layout calibration and machine/workload cache; candidates remain within the live resource plan.
- `desktop/src-tauri/src/environment.rs`: native read-only OS/hardware/tool/version/capability report and private run-mode toolchain resolver with encoder smoke checks; app-launched Python adapters delegate to it when dependency repair is disabled. Direct engine calls retain Python's resolver.
- `desktop/src-tauri/src/dependencies.rs`: native read-only cached APT installed/candidate version report for GUI, MCP, and JSON CLI. The desktop's reviewed combined missing-package/update flow is implemented in `lib.rs`; package transactions and digest-verified HDR10+ helper installation remain explicit user actions.
- `desktop/src-tauri/src/reports.rs`: native CSV report-history reads for GUI, MCP, and JSON CLI, plus fixed-schema CSV appends for Rust-launched engine rows; Python prepares row values and retains direct-run writing.
