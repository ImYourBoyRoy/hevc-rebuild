## Architecture

- `hevc_rebuild/config.py`: canonical settings defaults and precedence (built-in, user TOML, saved app profile in `settings.json`, library `.hevc-rebuild.toml`).
- `hevc_rebuild/encode.py`: per-file x265 resource plan, profile-aware memory forecast, live RAM/swap-pressure/disk guards, and quality-neutral retries.
- `hevc_rebuild/calibration.py`: bounded null-output x265 thread-layout calibration and machine/workload cache; candidates remain within the live resource plan.
- `hevc_rebuild/environment.py`: read-only Linux hardware, platform, and toolchain inspection.
- `hevc_rebuild/bridge.py`: JSON interface for environment, effective settings, folder scans (including per-file resource forecasts), reports, logs, and HDR helper install.
- `desktop/src-tauri/src/lib.rs`: typed Tauri commands, standalone `cli`/`json` dispatch, engine resource lookup, and Python child processes.
- `desktop/src-tauri/src/mcp_server.rs`: local stdio MCP server, typed analysis/run/repair tools, paged scan results, and bounded per-process job tracking.
- `desktop/src/routes/+page.svelte` and `desktop/src/app.css`: GUI workflow and visual system.

## Current decisions and boundaries

- Long-term portability goal: replace the Python media engine/runtime with a native Rust engine so releases do not require external Python; preserve current behavior and public interfaces during migration. Tracked in `todos.md`. Until then, Python remains authoritative.
- Version policy, verified 2026-09-25: Node 24.21.0 is the recommended LTS in `.nvmrc`; pnpm 12.6.0 is pinned by `packageManager`; `engines.node` accepts supported 22.12+, 24, and 26 lines. npm dependencies use compatible-major caret floors and a frozen lockfile. Rust dependencies use three-component caret floors and `Cargo.lock`. The locked npm and stable Rust crate versions were current for their compatible majors in the registry check. TypeScript 7.0.2 exists, but the standard Svelte checker peer range is TypeScript 5/6; TypeScript 7 currently requires the native compiler mode plus a parallel TypeScript 6 alias, so standard checks stay on TypeScript 6. Python is standard-library-only in this project.
- UI reads call `load_config(..., create_user=False)`; opening the GUI or scanning should not create the user config. Normal engine runs retain existing CLI behavior.
- Frontend defaults are loaded from effective engine config. Run edits stay temporary until saved as app defaults; the saved profile is shared by GUI, CLI, and MCP.
- App preferences use a native JSON file. AppImage state is in the writable sibling `<AppImage filename>.data/`; installed builds use `$XDG_CONFIG_HOME/hevc-rebuild-studio/settings.json`. The AppImage sidecar also holds engine TOML config, logs, and its managed HDR10+ helper.
- Environment and folder scans are read-only. Runs disable automatic dependency repair. APT repair is an explicit confirmed allowlist operation; HDR helper installation is separate.
- GPU inventory is informational; encoding remains CPU libx265.
- The v1.2.6 calibration capability is integrated with the current resource planner, CLI/config, desktop settings, reports, and typed MCP run settings. `auto` benchmarks uncached 4K/large sources, `ask` prompts only in an interactive CLI when uncached, `always` benchmarks each processed file with automatic threading, and `off` disables it. Cache hits are bounded by the fresh plan; calibration never writes media output and the live guard remains authoritative.
- Automatic x265 concurrency uses a transparent profile-scaled memory allowance from available/effective total RAM, finite cgroup headroom, PSI, dimensions, target precision, chroma, and preset lookahead. It is a heuristic, not exact peak-RSS prediction. Swap occupancy and host-wide in/out rates are tracked but not counted as RAM; sustained swap-in plus full-memory stalls trigger a lower-thread retry. Swap is not changed by the application.
- Light/Dark/Hacker appearance, selected library, FFmpeg override, scan filters, stop-on-error, and optional rebuild profile persist through native settings; previous localStorage values migrate once when no native file exists.
- CLI `cli` forwards to the engine; CLI `json` forwards only defined bridge operations and reserves stdout for JSON.
- MCP is a local stdio server with fixed typed operations; it does not expose shell execution or a network listener. It limits simultaneous scans, prevents scans and mutating jobs from overlapping, bounds retained output, and requires explicit run/repair inputs.
- Engine behavior supports Ubuntu 24.04+ and Ubuntu-based Linux Mint 22+. The `.deb` executable requires `GLIBC_2.39`. The current AppImage was built on Ubuntu 26.04.1 and includes GTK/WebKit libraries requiring `GLIBC_2.43`; rebuild from Ubuntu 24.04 before claiming AppImage compatibility there. Windows/macOS work requires platform and runtime design before implementation claims.
