HEVC Rebuild Studio v1.3.0 - quick start
========================================

The maintained guide is README.md. The short links are:

   docs/USAGE.md              GUI, CLI, MCP, output, and recovery workflows
   docs/TOOLS.md              FFmpeg, FFprobe, MediaInfo, MKVToolNix, HDR10+
   docs/SUPPORT.md            troubleshooting, support, and licensing
   docs/PROJECT-STRUCTURE.md  where source, tests, docs, and artifacts live

Direct engine on Linux:

   python3 -m hevc_rebuild --setup-only
   hevc-rebuild "/path/to/library" --recursive --info-only

Desktop preview on Linux:

   cd desktop
   pnpm install --frozen-lockfile
   pnpm tauri dev

The desktop app is a hybrid Rust/Python application while the migration is in
progress. Python 3 remains a host requirement for compatibility run
orchestration, reports, metadata, and direct engine paths. FFmpeg/FFprobe,
MediaInfo, MKVToolNix, and the HDR10+ helper are external tools managed by the
documented setup flow. Native pickers and drag-and-drop add files/folders to
the same saved Media Library queue.

Use Check only first, then Short test, then a confirmed Full rebuild. Originals
remain protected until validation passes. If a late stage fails after a
completed encode, keep the retained `<name>.error.mkv` beside its matching
`<name>.error.log`; the output is intentionally marked unvalidated.
